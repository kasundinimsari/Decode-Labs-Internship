# 🎣 Phishing Awareness Analysis

## 📌 Project Overview
This project was completed as part of the **DecodeLabs Cyber Security Internship – Project 03**. The objective was to analyze a sample phishing email, identify suspicious indicators, and explain why the message is unsafe.

## 🛡️ Key Learning Areas
- Phishing detection
- Social engineering awareness
- Email security analysis
- Suspicious domain identification
- Safe response practices

## 📧 Sample Phishing Indicators
- Fake domain (`paypa1-support.com`)
- Urgent language
- Threat of account suspension
- Suspicious external link
- Generic greeting

## 🔍 Analysis Performed
The email was examined to identify common phishing characteristics used by attackers to trick users into revealing sensitive information such as passwords and banking details.

## ✅ Recommended Safe Response
1. Do not click the link
2. Verify the sender's domain
3. Visit the official website manually
4. Report the email as phishing
5. Delete the email after reporting
