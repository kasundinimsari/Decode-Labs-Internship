# 🔐 Advanced Caesar Cipher Encryption & Decryption

## Overview

This project is a Python implementation of the Caesar Cipher algorithm developed for DecodeLabs Cyber Security Project 2.

The application allows users to encrypt and decrypt messages using a custom shift key while maintaining the integrity of spaces, punctuation, and numbers.

---

## Features

- Caesar Cipher Encryption
- Caesar Cipher Decryption
- Custom Shift Key
- Input Validation
- History Logging
- Menu Driven Interface
- Supports Uppercase & Lowercase Letters
- Preserves Spaces and Symbols
